# Human Resource Management System

## About the Project
A Human Resource Management System developed to manage employee records and designation records efficiently. The application supports CRUD operations (Create, Read, Update, Delete) and follows a layered architecture for better code organization and maintainability.

## Features
- Employee record management
- Designation record management
- CRUD operations for employee and designation records
- Database connectivity using JDBC
- Layered architecture

## Technologies Used

### Frontend
- JSP (JavaServer Pages)
- HTML
- CSS
- JavaScript

### Backend
- Java
- Servlets

### Database
- MySQL
- JDBC

### Server
- Apache Tomcat 9

## Architecture
- Presentation Layer
- Business Layer
- Data Layer

## Tools Used
- Eclipse IDE
- MySQL Workbench
- Apache Tomcat 9

## Purpose
This project was developed to practice Java web development, database connectivity, and layered application architecture.
